# Financial Time Series Forecasting

## Overview
This project focuses on analyzing and forecasting financial time series data using statistical modeling techniques.

## What I Did
- Performed time series decomposition
- Checked for stationarity
- Applied ARIMA modeling
- Evaluated forecast accuracy

## Why It Matters
Forecasting financial trends supports better planning, budgeting, and risk management decisions.

## Tech Used
Python, Pandas, Statsmodels, Matplotlib
